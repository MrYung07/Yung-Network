YUNG NETWORK — CYBER EDITION

FILE
- index.html: struttura e testi della pagina
- styles.css: grafica, responsive e animazioni
- script.js: menu mobile, animazioni e link Discord

PRIMA DI PUBBLICARE
1. Apri script.js.
2. Sostituisci https://discord.gg/INSERISCI-IL-TUO-INVITO con il link d'invito permanente o valido del tuo server Discord.
3. In index.html, aggiorna i nomi segnaposto dello staff e i testi/news dimostrativi.
4. Se hai un logo o avatar ufficiale, puoi inserirlo nella sezione staff o brand.

PUBBLICAZIONE SU VERCEL
Opzione A — progetto Git già collegato a Vercel:
- Fai una copia di backup del sito attuale.
- Inserisci index.html, styles.css e script.js nella cartella pubblicata del progetto, mantenendo eventuali altre pagine/risorse necessarie.
- Fai commit e push: Vercel creerà una nuova deployment.
- Controlla l'anteprima prima di promuoverla in produzione.

Opzione B — nuovo progetto statico:
- Carica la cartella (o uno ZIP) tramite https://vercel.com/drop.
- In alternativa importa il repository Git da Vercel.
- Per HTML/CSS/JS puro scegli Framework Preset: Other; nessun build command è necessario. La cartella pubblicata deve contenere index.html alla sua radice.

NOTE
- Font Google richiede una connessione internet; in assenza di rete si usano font di fallback.
- Le news sono contenuti dimostrativi, non un feed automatico.
- Nessun dato dello staff o collegamento Discord reale è stato inventato.
